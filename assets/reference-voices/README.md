# Bundled Irodori reference voices

These WAV files are bundled only as reference voices for CharaDock's Irodori
TTS integration. They are not a standalone voice-material pack and must not be
extracted or redistributed separately from the application.

## `hiro.wav`

- Original local filename: `Recording (12)`
- Speaker and rights holder: ochisamu
- Permission: recorded by and bundled with the speaker's permission

## `kohaku.wav`

- Original local filename: `rusuden_02`
- Voice material: あみたろの声素材工房
- Credit: あみたろの声素材工房（https://amitaro.net/）
- Current terms: https://amitaro.net/voice/voice_rule/

Use of `kohaku.wav` remains subject to the current rules published by
あみたろの声素材工房. In particular, do not redistribute it as voice material
or use it for prohibited content, impersonation, fraud, or misleading speech.
If the upstream rules change, the current upstream rules take precedence over
this summary.
